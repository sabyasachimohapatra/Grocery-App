<h1 align="center">🛒 Grocery App – Full Stack Web Application 🛒</h1>

A full stack grocery management web application designed to provide a smooth and efficient shopping experience. Users can browse products, manage their cart, and place orders through a clean and responsive interface.

---

## ✨ Features

- 🛍️ Browse grocery products with a user-friendly interface  
- 🧾 Add and remove items from the shopping cart  
- 🔐 Secure user authentication  
- 📦 Order management functionality  
- ⚡ Fast and responsive UI  
- 🌐 RESTful API architecture  
- 🚨 Proper frontend and backend error handling  
- 🧠 Scalable and well-structured codebase  

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript, React  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Styling:** CSS / Tailwind CSS  

---

## 🧪 Environment Variables Setup

### Backend (`/backend`)

Create a `.env` file inside the backend directory and add the following:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret_key
NODE_ENV=development
```
## 🔧 Run the Backend

```bash
cd backend
npm install
npm run dev
```

## 💻 Run the Frontend

```bash
cd client
npm install
npm run dev
```
